HyperText Markup Language (HTML) = Язык гипертекстовой разметки

<h1-h6> = Тег, размер которого зависит от цифры. h1 - самый большой
<p> = заголовок

<strong> = делает слово/слова жирным шрифтом (семантический тег, несет смысл важность) 
<b> = выделяет жирным шрифтом (визуальный тег) 

<em> = курсив (семантический тег)
<i> = курсив (визуальный тег)

<ul> = unorder list (неупорядоченный список) ; <li> = один пункт списка 
<ol> = ordered list (упорядоченный список) ; <li> = один пункт списка 
<dl> description list (список описаний); dt = description term (дата); dd = description definition (определение)


<img> = одиночный тег, для картинки <img src="" (source = ресурс) alt="">
<a> = ссылка <a href=""> (hypertext reference) </a>

<span> = пустой строчный контейнер (span = промежуток)
<span style="color: red">

Семантические теги:
<header> = вводная часть
<nav> = навигатор (ссылки на разделы страницы)
<main> = основной контент ; <section> и <article> внутри main для удобства
<aside> = боковая панель
<footer> = низ страницы

<br> = Перенос стоки (break)
<hr> = Горизонтальная линия (horizontal rule)
&nbsp; = гарантированный пробел (non-break space) 

id="" = связывается с href="#" с помощью # в ссылки
